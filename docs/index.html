Data-Driven Science & Engineering

Interactive notebooks on the mathematics behind modern data analysis. Each one is a short chapter you can read, then take apart yourself.

  • Runs in your browser
  • WebAssembly · no install, no server
  • Built with marimo

Two ways to read

Launch the app

Code hidden. You get the controls and the figures. Drag a slider and watch the mathematics respond.

Read the notebook

Each function on show, beside the derivation it implements. Read it top to bottom, then reproduce it yourself.

Chapter 01

A Signal Is a Vector

Start here. One dimension, small enough to see every number. A signal is a point in ℝⁿ, and compression is nothing more than choosing better coordinates. Watch a smooth signal go from 64 dense samples to a handful of Fourier coefficients.

Chapter 02

Compression via Sparsity

The same move in two dimensions: dense pixel space to sparse transform space, the idea behind JPEG, JPEG 2000, and most lossy image compression. Load any image, choose a basis (FFT · DCT · wavelet), then drag the keep-% and watch the reconstruction, the coefficient field, and PSNR update together.
